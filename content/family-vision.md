# The design-sites family vision

Bridger's founding document for the content of the family (2026-08-14),
captured at the charting of the site-content effort. The per-site working
docs (`design-styles.md`, `design-reference.md`, `design-philosophies.md`)
inherit from this; where they conflict, this document wins until a brief is
locked.

## The verb framework

Each site owns a different verb:

| Site | Verb | Core question | Primary value |
| --- | --- | --- | --- |
| **design-styles** | See | "What does this look like?" | Discovery and visual literacy |
| **design-reference** | Use | "What value, rule, or format do I need?" | Fast, repeat utility |
| **design-philosophies** | Think | "What does this approach believe?" | Context and critical judgment |
| **design-books** | Read | "Where can I go deeper?" | Canonical sources |

## design-styles

**A visual field guide to the movements and visual languages that shape
design.** Organized timeline-wise around movements.

Historical movements and contemporary UI styles live in one collection as two
content types:

- **Movements** have historical context, participants, geography, and often
  an articulated agenda: Bauhaus, De Stijl, Memphis, International
  Typographic Style.
- **Styles** are recognizable visual languages that may be diffuse, revived,
  or digitally native: neubrutalism, glassmorphism, vaporwave, corporate
  Memphis.

Not divided by past/present — every entry carries attributes:

- Type: movement or style
- Status: historical, revived, current, emerging
- Period and place
- Medium: graphic, editorial, identity, interface, product
- Influences and descendants

Each page is a **visual specimen**, not a conventional article:

1. One-sentence definition
2. Annotated visual examples
3. Visual grammar: type, color, form, grid, imagery, material and motion
4. Origins and context
5. Key figures and works
6. "Often confused with"
7. Contemporary applications
8. Related philosophies and books

Interface feels exploratory: visual index, timeline, filters, side-by-side
comparison.

## design-reference

**The practical reference desk for the facts, standards and calculations
designers use repeatedly.** A reference system with embedded tools — not
merely a lookup site, not a generic tool collection.

The rule:

> If the user only needs an answer, give them the answer immediately. If the
> answer changes based on an input, add a tool.

Examples: paper sizes → table with copyable dimensions · WCAG contrast →
thresholds plus a checker · type scales → explanation plus generator ·
aspect ratios → chart plus calculator · safe areas → dimensions plus visual
preview · px/rem → table plus converter.

Every page contains:

1. The answer at the top
2. A compact table or diagram
3. When it applies and important exceptions
4. Interactive controls when genuinely useful
5. Copy, export or share actions
6. Primary source, version and "last verified" date

Homepage is search-first and extremely fast — no editorial introduction
before the number someone came to find. Likely the strongest repeat-use
product; could eventually expose the same structured information via JSON, an
API, or agent-readable access (build-time concern).

## design-philosophies

**An annotated atlas of the ideas, values and arguments behind design.**
Source-faithful but clearly authored — pure encyclopedia neutrality would
flatten the subject and remove the part that makes it Bridger's.

The editorial principle:

> Steelman first, position second.

Each entry: 1. What it believes · 2. Where it came from · 3. Primary claims
or principles · 4. What it asks a designer to do differently ·
5. Representative work · 6. Tensions, criticisms and limitations ·
7. Bridger's field note (useful or unconvincing, and why) · 8. Canonical
texts on design-books.

Distinguishes kinds of ideas: **authored systems** (Rams' principles, calm
technology) · **schools of thought** (functionalism, human-centered design) ·
**cultural traditions** (wabi-sabi, Mingei) · **positions and debates**
(ornament, universality, repairability, meaningful friction).

Homepage organizes around **tensions** rather than an alphabet: permanence vs
impermanence, universality vs situated design, reduction vs expression,
control vs emergence.

## How the family connects

Distinct sites, shared identity — working name "A Design Source project"
(tentative) — with a common relationship system underneath. Each subject has
**one canonical home**; the others link to it. Example, Swiss design:

| Site | Swiss-design subject |
| --- | --- |
| design-styles | International Typographic Style |
| design-reference | Grid, typography and layout references |
| design-philosophies | Modernist functionalism and universality |
| design-books | *Grid Systems in Graphic Design* |

Strategic roles: styles attracts through visual discovery · reference earns
bookmarks and repeat visits · philosophies establishes the editorial voice ·
books provides depth and original sources.
