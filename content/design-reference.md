# design-reference.com

Working document for what this site becomes. Sibling of design-books.com —
same care, its own face.

## Premise

_One line: what is this site?_ (draft) The reference desk for working
designers — the numbers, standards, and lookups you keep re-googling, in one
fast, trustworthy place.

## Why this site

Every designer re-searches the same facts: type scale ratios, WCAG contrast
thresholds, paper sizes, screen densities, safe areas, grid math, color
spaces. The sources are scattered, ad-choked, or buried in specs.

## Audience

Practicing designers mid-task. This site is a tool you visit with a question,
not a publication you read.

## Content model

_What is one entry?_ (sketch) A **reference card**: a single lookup
(e.g. "WCAG contrast ratios", "ISO paper sizes", "iOS tap target minimums")
with the answer up top, the nuance below, and the primary source cited.
Possibly interactive where it earns it (a contrast checker, a scale
calculator).

## Seed entries

Type scale ratios · WCAG contrast thresholds · ISO/US paper sizes ·
Screen sizes & densities · iOS/Android touch targets & safe areas ·
Grid & baseline math · Color space cheat sheet (sRGB/P3/OKLCH) ·
File format decision table (SVG/PNG/WebP/AVIF) · Common blend modes ·
Accessibility quick checks · Favicon/OG image size matrix
