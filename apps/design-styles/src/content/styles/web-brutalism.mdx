## Origins

Mid-2010s. A reaction to the polished web — the same card, the same sans, the same hero. Some sites answered by looking like 1997 on purpose: default type, blue links, no card.

The catalog at brutalistwebsites.com named the scene. It was never a system. That is the point. A system would be a design.

Neubrutalism arrives later and turns the stance into a kit. The parent looks uglier and more honest. The child looks louder and more designed.

## In the wild

Rare as a full site now. The catalog aged out. You still see the stance in personal sites that refuse a framework, and in jokes.

The cheap version is a Google Font pretending to be a default. The real thing is the default.
